# Prompt v43 生产效果评估（对照 v41/v42）

**日期：** 2026-10-14
**方法：** 按归档 `APPENDIX.__PROMPT_VERSION__` 分组统计生产数据
（v41: 68 条，v42: 90 条，v43: 519 条）。
**注意：** 各版本样本时段不同、模型组合可能有漂移，以下对比为观察性证据而非严格实验。

## 1. 结构完整性：v43 全面优于 v42 远优于 v41

| 指标 | v41 | v42 | v43 |
|---|---|---|---|
| 事件数/记录 | 1.46 | 1.64 | **1.78** |
| 实体数/记录 | 2.74 | 4.02 | **4.38** |
| 含限定词 | 39.7% | 57.8% | **65.9%** |
| 含地点 context | **0%** | 33.3% | **41.0%** |
| 含时间 | 25.0% | 56.7% | **60.3%** |
| 含事件关系 | 32.4% | 27.8% | **44.5%** |
| 物理实体国别标注率 | 78.8% | 72.1% | **78.0%** |

子集化（内联实体、位置序号关系）持续兑现收益；v41 的 context 完全缺失问题在 v42+ 消失。

## 2. 质量检查（__EXTRACTION_QUALITY__）

| 指标 | v42 | v43 |
|---|---|---|
| 检查覆盖率 | 90/90 | 519/519 |
| 未登记角色 | 0（0%） | 17（3.3% 的记录） |
| 角色-类型冲突 | 2（2.2%） | 12（2.3%） |
| predicate 接地率 | 83%（123/148） | **59%**（544/924） |

角色类指标按记录比例持平；**接地率下降明显**——抽取章节两版相同，疑似模型组合漂移
（v43 期间生产客户端组合有变化）或样本构成差异，建议后续按 `__AI_MODEL__` 细分复核。

## 3. RATE 词表化效果：机制正确，但出现档位聚集

映射机制工作正常：v43 的 RATE 只出现映射表中的离散值，unknown 无塌缩
（可行动性最低档仅 13/519）。

但**模型明显向"安全中档"聚集**：

| 维度 | 主导档位 | 占比 |
|---|---|---|
| 可行动性 | monitorable(4) | **94%** |
| 影响深度 | material(6) | 82% |
| 舆情及认知影响 | visible(5) | 81% |
| 新颖性与异常性 | uncommon(4) | 81% |
| 演化与连锁潜力 | contained(4) | 69% |
| 影响广度 | local(4)/national(7)/international(8) 三峰 | — |

**下游影响显著**：总分 >6 的比例 v41 38% → v42 36% → **v43 5.6%**（均值 5.75→5.85→5.11）。
以分数做筛选/推送阈值的业务需要知悉这一分布迁移。

## 4. 结论

- v43 **机制上成功**：确定性映射、零校验失败（无新增失败类别）、结构更完整；
- v43 **评分区分度退化**：词表没有准入/排除条件，模型倾向选"中间安全档"，
  六维度中五个存在单一主导档位。这印证了词表化讨论中"不能只换词、要配定义边界"的告诫。

## 5. 后续建议（v44 候选）

1. 为聚集最严重的维度（可行动性、舆情、新颖性、演化）补充档位**准入/排除条件**
   （如 monitorable 的排除条件："正文存在明确可执行对象与窗口时不得选此档"）；
2. 影响广度保留三峰是合理现象（新闻确以局部/全国/跨国为主），但 4→local 占比偏高，
   可加"单个组织设施 → organization，不要默认 local"的排除条件；
3. 按 `__AI_MODEL__` 细分复查接地率下降归因；
4. v44 上线前用固定样本集（`Scripts/compare_prompt_v41_v42.py`）对比档位分布离散度。
