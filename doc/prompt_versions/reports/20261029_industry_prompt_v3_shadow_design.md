# Industry Prompt v3：保守评分与详细解释 Shadow

> 状态：v1 为唯一正式版本，v3 为 25% 同模型 Shadow 候选；v2 保留历史回看。

## 1. 来自 v1/v2 首批配对的结论

13 组成对样本中有 12 组使用同一模型。v1/v2 的有价值率相同，但出现一次“v1 收录、v2 拒绝”
和一次“v1 拒绝、v2 收录”；双方都收录的 8 组总分均值几乎不变。v2 的主要价值不是整体提分，
而是 REASON 更具体，并能识别经营状态冲击、经营冲突和可执行产业政策。

主要问题是普通财报与经营状态冲击的边界仍有冲突；规则增多后，模型偶尔让背景政策或一般财务指标
挤占更关键的公司行动，且部分维度缺少独立证据仍会同步升档。

## 2. v3 目标

1. 保留 v2 的四类信号覆盖和详细 REASON。
2. 财报按事实增量判断，不因载体自动收录或排除。
3. 评分从低档开始，逐维具备证据才升档，不预设平均分必须下降多少。
4. 优先提取决定性经营变化、因果资源动作和约束性承诺，避免汇编背景挤占事件名额。
5. 比 v2 更短，继续使用相同 schema、等级映射、评分器和 Event Registry，保持单变量归因。

## 3. 关键规则

- REASON 按“信号类型；决定性新增事实；影响变量；关键限制”组织，并解释没有更高评级的原因。
- 公司行动、经营状态冲击、经营冲突和产业政策分别设硬准入门槛；四类均不满足即低价值。
- 财报只有在揭示盈利转折、历史极值、显著偏离目标，或量化资源配置变化影响经营判断时才进入。
- 每个 RATE 维度从最低合理档逐级检查；知名度、绝对数字、官方身份和热门题材不得补证。
- 有价值结果只选一至三项决定性事件；背景事实不得为了凑数进入事件结构。

## 4. 运行与检查点

- 正式池：v1；Shadow 池：v3；`sample_rate=0.25`；`comparison_mode=same_model`。
- 首轮 20 组检查财报边界、分类反转、REASON 信息密度和整体升档；50 组后再判断是否扩大。
- 不只比较平均分：重点人工复核分类不一致、单维变化 ≥2、事件主次变化和不同模型分层。
- 模型不同、Shadow 失败和重复报道必须单独标记，不混入干净 Prompt 配对结论。
