退出抽样但保留显式选择。影子采样率为 0。本报告只统计 `shadow=0` 的主链调用，并按
模型分层；运行统计来自 `_data/analysis_stats.db`，Token 来自以 `request_id` 关联的
`_data/ai_client_observations.db`，抽取完整度来自 MongoDB 的 Event V4 归档。

完整 Prompt 静态长度：v48 为 21,822 字符，v52 为 15,936 字符，v52 是 v48 的 73.0%。

## 5. 判定

v52 已达到目标样本量，但不满足替代 v48 的既定条件：

- DeepSeek、MiMo 的实体数分别下降 8.9%、7.0%；
- 角色绑定分别下降 13.9%、10.7%；
- DeepSeek 角色—类型冲突没有低于 v48；
- 主力模型全链路 Token 均未下降至少 10%；
- MiMo 首过率继续下降。

因此 v52 不应晋级为唯一生产版本，且按
[v52 灰度设计](20261021_prompt_v52_gray_design.md)中的停止规则，应退出生产随机抽样并保留
为显式对照。下一候选版本应保留 v52 的时间覆盖、接地率和角色白名单收益，但删除或改写
“无法放入合法角色便省略实体”的激进纪律，并把实体/角色完整度作为首要回归门槛。

本报告仅记录评估结论，不自动修改 `PromptCatalog` 抽样配置。
