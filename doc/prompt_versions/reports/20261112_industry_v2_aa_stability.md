# Industry Prompt v2 A/A 稳定性实验

> 启用日期：2026-11-12（Asia/Shanghai）
> 首个检查点截止：2026-11-23（Asia/Shanghai）
> 实验 ID：`industry-v2-aa-20261112`
> 配置：正式 v2；25% 确定性抽样；`comparison_mode=replicate`
> 检查点结论：已取得 133 组严格配对。分类和评分总体稳定，但分类边界、完整事件集合与
> 实体集合仍有不可忽略的重复分析波动；本实验作为后续 Prompt A/B 的噪声基线，不单独触发转正。

## 目的

本轮不比较 Prompt 优劣。对同一输入使用同一 v2 Prompt、同一最终客户端和模型重复分析，测量
温度为 0 时仍存在的模型固有波动，为后续 A/B 的分类、评分、事件和实体差异建立噪声基线。

## 运行边界

- 新样本固定使用 v2；已有 cache 中已分配 v4 的任务继续按 v4 完成，但不进入 v2 A/A；
- 抽样键为 `SHA256(experiment_id + domain_name + UUID)`，重启和重试不改变分组；
- 正式高价值结果归档后投递 Shadow；低价值结果写入低价值库后投递；
- Shadow 使用独立 worker，不阻塞正式分析和归档；
- 最终客户端名或模型不一致时不写入 A/A 资产；
- MongoDB 以领域、UUID、实验 ID 和 Shadow 版本幂等 upsert。

## 首次检查点口径

至少取得 100 组严格配对后评估：

1. 首过率的配对一致性及 McNemar 分歧；
2. Intelligence/NonIntelligence 分类分歧率；
3. RATE 各维一致率与总分绝对差；
4. 主事件谓词、事件集合、实体集合与抽取质量波动；
5. 按模型和主要来源分层后的稳定性；
6. 额外调用、Token 和延迟成本。

该实验只产生基线，不直接触发 Prompt 转正结论。

## 2026-11-23 检查点结果

### 实验完整性

- 共 133 组严格配对，全部能匹配正式归档，未发现孤立 Shadow 资产；
- 133 组的 Prompt SHA-256、最终模型、AI 服务和客户端名在主链与 Shadow 间均完全一致；
- 最终模型为 `deepseek-flash` 131 组、`Kimi CLI Stateless` 与 `Codex CLI Stateless`
  各 1 组；因此本轮结论主要代表 DeepSeek Flash；
- 记录跨两个代码 revision 标签：`fc8271f5` 62 组、`ef33e0bb` 71 组。两层的分类一致率
  分别为 96.8% 和 93.0%，双方有价值样本的总分 MAE 分别为 0.279 和 0.287，未见明显
  分层漂移；每组内部仍是同 revision、同 Prompt、同最终客户端的严格配对。

### 分类稳定性

| 主链 | Shadow | 数量 |
|---|---|---:|
| 行业情报 | 行业情报 | 91 |
| NonIntelligence | NonIntelligence | 35 |
| 行业情报 | NonIntelligence | 4 |
| NonIntelligence | 行业情报 | 3 |

分类一致 126/133（94.7%），分歧 7/133（5.3%，Wilson 95% CI 2.6%–10.5%）。
两个翻转方向为 4:3，精确 McNemar 检验 `p=1.0`，没有单向偏置。双方均判低价值的
35 组中，`NON_INTELLIGENCE_REASON` 有 33 组完全一致。

7 条分歧全部位于产业域准入边界：匿名供应链消息、观点或综述中嵌入的技术发布、历史经营
数据回顾、产业量产进度汇编、监管报告与财报二次解读、行业数据周报。其共同问题不是输出
Schema，而是“文章体裁”与“正文内可核验新增事实”谁应优先，以及行业级经营状态冲击能否
独立准入。单次分析约 5% 的归档/低价值翻转应视为当前 v2 + 模型组合的业务噪声。

### RATE 与总分

只统计双方均为行业情报的 91 组：

| RATE 维度 | 完全一致率 | 平均绝对差 | Shadow−主链均值 |
|---|---:|---:|---:|
| 行动实质性 | 87.9% | 0.363 | +0.363 |
| 规模与力度 | 82.4% | 0.363 | +0.319 |
| 事实确定性 | 95.6% | 0.176 | 0.000 |
| 认知增量 | 92.3% | 0.154 | +0.022 |
| 预期差与异常性 | 79.1% | 0.495 | +0.121 |
| 经营与战略影响 | 89.0% | 0.220 | +0.132 |
| 投资可用性 | 85.7% | 0.286 | +0.110 |
| 关注度与故事性 | 93.4% | 0.132 | 0.000 |

总分差（Shadow−主链）均值为 +0.156，中位数为 0，MAE 为 0.284，RMSE 为 0.510；
Pearson 相关系数 0.870，Spearman 相关系数 0.849。47/91 完全同分，72/91 的绝对差不超过
0.5，83/91 不超过 1.0，最大绝对差为 2.1。

重复分析存在小幅升分倾向：均值差 95% CI 约为 +0.054～+0.258，配对检验
`p≈0.003`。该差异在业务尺度上较小，但后续 A/B 若只观察到约 0.2～0.3 的平均分变化，不能
脱离分类翻转和结构质量单独认定为 Prompt 改进。最不稳定的 RATE 是“预期差与异常性”和
“规模与力度”；Shadow 在行动实质性、规模和经营影响上略偏高。

### 事件、实体与抽取质量

同样只统计双方均为行业情报的 91 组：

| 指标 | 结果 |
|---|---:|
| 主事件谓词一致 | 82/91（90.1%） |
| 完整谓词多重集合一致 | 59/91（64.8%） |
| 谓词集合平均 Jaccard | 0.806 |
| 实体集合完全一致 | 26/91（28.6%） |
| 实体集合平均 Jaccard | 0.669 |
| 事件数量一致 | 74/91（81.3%） |
| 实体数量一致 | 50/91（54.9%） |
| `SUB_CATEGORY` 集合一致 | 85/91（93.4%） |

模型通常能抓住同一主事件，但会改变次级事件拆分、背景参与者收录和实体粒度。因而后续
Prompt A/B 不能只比较主事件或数量，必须同时报告完整谓词集合和实体集合的语义相似度。

质量统计中的“未登记角色 + 角色类型冲突”为 Shadow 更优 2、持平 87、更差 2，双方问题
总数均为 7。该结果说明结构合法性没有方向性漂移，但不能替代上述语义集合稳定性指标。

### 首过率、调用量与延迟

| 指标 | 主链 | Shadow |
|---|---:|---:|
| 首次通过 | 85/133（63.9%） | 84/133（63.2%） |
| 第 2 次通过 | 37 | 38 |
| 第 3 次通过 | 11 | 11 |
| 最终成功 | 133/133 | 133/133 |

首过率的配对状态为：双方首过 69、仅主链首过 16、仅 Shadow 首过 15、双方均需纠错 33；
精确 McNemar 检验 `p=1.0`。这说明首过失败既有系统性 Schema 难点，也有明显的重复生成波动。

形成 133 个 Shadow 成功结果共调用模型 193 次，累计模型调用耗时约 1007 秒；每个 Shadow
任务平均 7.57 秒、中位数 5.32 秒、最大 53.87 秒。Shadow 独立 worker 不把这些耗时加入正式
归档等待，但会产生真实调用成本。当前统计未保存 Token 数量，不能可靠换算 Token 或货币成本。

配对样本的 60 次 Shadow `schema_shape` 失败中，49 次（81.7%）包含 `EVENT_BRIEF`、
`REASON`、`EVENT_TITLE` 或 `IMPACT` 超长；其中最常见的是 `EVENT_BRIEF:string_too_long`。
因此首过率问题首先是文字预算遵循，而不是事件 Schema 自造字段。

## 与 v4/v6 Shadow 实验的联合解释

前一轮 [`industry-v4-v6-20261101`](20261112_industry_v4_v6_shadow_evaluation.md) 有 112 组
严格 v4→v6 配对。将其与本轮 A/A 放在同一实验链中：

| 指标 | v4→v6 A/B | v2→v2 A/A 基线 | 联合解释 |
|---|---:|---:|---|
| 分类分歧 | 7/112（6.25%） | 7/133（5.26%） | 同一量级，A/B 分歧不能直接归因于 v6 |
| Shadow 首过率变化 | +3.6 个百分点 | -0.7 个百分点 | v4→v6 提升不显著（`p=0.424`） |
| 双方有价值总分均值差 | -0.037 | +0.156，MAE 0.284 | v4→v6 分差小于模型重复噪声尺度 |
| 角色问题方向 | 更优 3 / 持平 67 / 更差 3 | 更优 2 / 持平 87 / 更差 2 | 两轮均无稳定方向 |

v2 A/A 不是 v4 A/A，不能作为 v4→v6 的完全同分布反事实；两轮的正式 Prompt、时间窗口和
样本组成不同。但它首次量化了同领域、相同主要模型、温度 0 下的重复分析噪声。此前 v4/v6
观察到的分类、总分和角色差异均未明显超过该基线，因此“A/B 未显示稳定净改进、v6 不转正”的
原决策得到加强，而不是被推翻。

## 后续实验准入建议

1. 后续 A/B 必须保留稳定 `experiment_id`、确定性抽样和严格同最终客户端配对；
2. 分类变化需与 5.3% A/A 翻转基线比较，并逐条审计两个翻转方向；
3. 平均分变化约 0.2～0.3 时默认视为噪声候选，至少同时报告 MAE、配对分布和 RATE 维度；
4. 事件抽取报告必须包含主谓词、完整谓词集合、实体集合及 Jaccard，不能只报事件数量；
5. 首过率实验应把文本超长与闭集 Schema 错误分开统计；
6. 若下一候选专门修改产业准入，应建立匿名传闻、评论/综述、量化经营回顾和行业数据汇编的
   固定困难样本集，并在正式 Shadow 前做人工判定。
