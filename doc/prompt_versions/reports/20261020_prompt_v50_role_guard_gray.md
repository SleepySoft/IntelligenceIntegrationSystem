## v50 修复

v50 保持 v49 的章节、目录压缩和 `core_subset_levels_reason` 协议，只在实体/角色章节
增加输出前检查：

- 已登记谓词的每个角色键必须命中公共角色或当前谓词行的白名单。
- 明确 actor/agent/subject/affected 及语义组不是可跨谓词套用的输出槽位。
- 行动/权威、地点语义组的角色名由当前 Registry 动态汇总，并声明合法实体类型。
- 明确政府机关/军队/企业/社会团体为 organization；事件、现象、政策、设施不得
  冒充行动/权威角色。
- 自然现象作为原因但登记谓词无合法槽位时，改用 `agency=non_agentive` 的开放谓词。

  与 Prompt 质量指标分开统计。
