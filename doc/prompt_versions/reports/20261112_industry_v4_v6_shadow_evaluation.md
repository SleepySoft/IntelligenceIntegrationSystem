# Industry v4/v6 Shadow 评估结论

> 统计截止：2026-11-12（Asia/Shanghai）
> 实验：正式 Prompt v4 对 Shadow Prompt v6，25% 同模型抽样
> 结论：v6 不转正；保留 v4 为唯一正式版本，停止 v4/v6 实验后先做 A/A 稳定性基线。

> 后续决策：完成 P1 实验基础设施改造后，操作者选择将历史 v2 重新设为正式版本，
> 并执行 `industry-v2-aa-20261112` 的 25% v2/v2 A/A；v4 不再接收新生产样本。

## 1. 样本边界

- MongoDB `analysis_shadow` 中有 112 组严格 v4→v6 配对，全部能匹配正式归档；
- 最终模型为 `deepseek-flash` 111 组、`mimo-v2.6-flash` 1 组；
- 界面新闻与 OFweek 三个频道共 95/112，结论主要代表当前高频来源和 DeepSeek Flash。

## 2. 结果

| 指标 | v4 | v6 |
|---|---:|---:|
| 首次通过 | 94/112（83.9%） | 98/112（87.5%） |
| 最终成功 | 112/112 | 112/112 |
| 平均尝试次数 | 1.17 | 1.13 |
| 判为有价值 | 78 | 77 |
| 谓词接地 | 98/160（61.3%） | 104/165（63.0%） |

首过率配对变化为：v6 修复 9 条、回退 5 条、其余 98 条不变。精确 McNemar
检验 `p=0.424`，+3.6 个百分点未达到统计显著。双方均判为有价值的 73 组中，平均总分差
为 -0.037；角色问题为 v6 更优 3、持平 67、更差 3，未见结构质量的稳定提升或恶化。

分类一致 105/112（93.8%），7 条分歧包含公司自研技术量产、财报经营冲击、立法进展、
融资洽谈、技术原型和行业汇编等边界。快速复核显示多数分歧更接近 v4 的既有准入规则，
但当前没有同 Prompt A/A 基线，不能区分 Prompt 影响和模型固有非确定性。

## 3. 运行成本

v6 为 111 个入组样本增加 126 次调用和约 528.5 秒调用时间。旧实现同步占用分析 worker；
2026-11-12 的 P1 改造已把 Shadow 移至正式结果持久化后的独立 worker，并采用确定性抽样。

## 4. 决策

1. v6 不转正，v4 保持唯一正式 Prompt；
2. 冻结本轮实验为 `industry-v4-v6-20261101`；
3. 下一实验先做正式 Prompt 的 25% A/A 重复分析，测量分类、评分、实体和谓词的固有波动；
4. 在 A/A 基线完成前不继续叠加 Schema Prompt 文本。
