# 态势洞察（SituationViews）

Event V4 的只读地缘态势、实体关系与实体时间线看板。该目录可整体移除；它只读取归档集合和派生事件
索引，不写数据库，也不参与采集、分析、评分、归档、聚合或图谱扩展。

IIS 内向 `IntelligenceViews` 集成页提供三个嵌入组件：

- `/situation/embed/map`：地缘态势；
- `/situation/embed/entities`：实体关系。
- `/situation/embed/timeline`：可多选实体的事件时间线。

三个页面的子系统、滚动时间窗口上限、最低评分和图规模由服务端配置固定。地图与实体图可在
已加载窗口内用双端时间轴缩小显示范围；拖动时完全由浏览器隐藏/显示既有图元并更新聚合数字，
不请求后端、不重建实体图布局。事件类别和实体类型仍可通过右上角可折叠悬浮图例进行筛选。
旧的 `/situation/`、
`/situation/map` 和 `/situation/entities` 不再注册。

独立运行（直接读取 `_config/iis.yaml` 指向的真实 MongoDB）：

```bash
python -m SituationViews.standalone
```

然后访问 `http://127.0.0.1:5010/situation/embed/map`。

IIS 主站会把同一套只读组件挂载到 `/situation/embed/*`，并复用主站的
`SubsystemRegistry`，但不进入 Hub 事件链。当 `intelligence_views.public_access=true` 时，
仅嵌入页面和固定范围的 `/situation/api/scoped/*` 随 `/views` 公开；可自定义查询范围的
非 scoped API 仍要求登录。可以在 `_config/iis.yaml` 中单独关闭整个
模块或地名解析：

```yaml
optional_subsystems:
  situation:
    enabled: true
    subsystem: news
    window_days: 7
    min_score: 6
    geocoding: true
  intelligence_views:
    public_access: true
    public_window_days: 7
    public_timeline_max_entities: 4
```

`public_window_days` 是未登录用户共享的地域图、实体图和实体时间线查询上限，不能超过
`situation.window_days`；空值沿用后者。`public_timeline_max_entities` 在页面、父级 URL
编排和 scoped API 三层强制执行，登录用户仍使用 8 个实体上限。没有该配置段时使用代码
默认值。模块初始化失败不会阻断 IIS 主服务；若仅地名
解析初始化失败，国家级热点和实体关系图仍可使用。`SituationViewsService.mount_to_app()`
仍可供独立程序或其他 Flask 应用直接挂载。

情报列表、地缘态势、实体关系和实体时间线的四个视图 Tab 由 IIS Core 之外的 `IntelligenceViews`
纯展示模块提供。集成页只组合已有子页面；地图或实体图逻辑不进入
`IntelligenceHubWebService`，四个视图也不互相直接依赖。

实体时间线使用重复 `entity` URL 参数；登录用户一次最多选择 8 个稳定或临时图实体 ID，
未登录用户采用上述公开配置上限。默认将它们
作为一个临时实体组聚合显示，也可切换为逐实体分轨对照；聚合仅影响浏览，不写回实体别名或
解析表。时间线把所选实体画成中心时间轴，把事件放在轴上；外部实体节点在轴两侧分层避碰，
多条平滑关系曲线汇入事件锚点，曲线上显示规范谓词。箭头保持事件关系中施事到受事的方向。
同一事件有多条关系时，曲线使用独立扇入角度；多层节点沿轴方向错位，不形成会遮线的垂直列。
横向/纵向和聚合/分轨都只在浏览器内重排，滚轮缩放、
拖动画布、适配全图与 1:1 复位不请求后端。轴长随事件数量增长并保持事件锚点的最小间距，
避免把整个窗口压缩到单屏后标签重叠。日级及以上的明确事件时间按抽取时间定位；只有年或月的
粗粒度时间不能被伪装成 1 月 1 日或当月 1 日，因此改按文章内容时间定位，并在详情中同时显示
原始规范化时间和精度。完全缺失事件时间时同样回退文章内容时间并醒目标记。页面顶部的“最近
N 天”明确表示情报收录窗口，不承诺其中描述的所有事件都发生在该窗口内。时间线使用独立的定向
投影接口，不受实体图的
`max_nodes`/`max_edges` 裁剪；共同出现、跨文章支撑和跨来源支撑分开统计，避免把同文共现误称
为独立来源印证。

实体图选中节点后可直接把稳定图实体 ID 带入时间线。地域图选中国家或细化地点后，会先在
同一服务端窗口内按地域名称和国家代码查询可用实体，选择名称、类型和事件数排序后的最佳
地域实体，以 `entity` 参数切换时间线；找不到匹配时停留在原视图并给出明确提示。

当前地图只使用 `event_location` 中明确给出的 ISO 两位 `country_code`，在国家中心显示
热点；点击热点会在页面底部以默认收起的摘要栏加载对应情报，栏内显示名称和情报数量，
结果更新时短暂闪烁，不会强制遮住地图。点击摘要栏或“展开”后才显示真实情报卡片，标题
使用与主站情报列表相同的详情弹窗在当前页面展示完整 DETAIL 投影；切换热点时保持用户当前
的展开/收起状态。抽屉可收起、重新展开或关闭，
并在内部独立滚动，不依赖滚轮越过地图。单次最多
返回最新 50 条，避免热点数据量增大后拖慢地图首屏。具体地点名称会随热点详情展示，但在
放大到区域级别后才会由独立后台任务按需解析坐标并逐步显示。解析结果缓存在
`_data/SituationViews/geocoding.sqlite`，外部坐标来自 OpenStreetMap Nominatim；解析失败的
地点不会伪造坐标，也不会影响国家级热点和其他功能。

实体关系图依据 Event Registry 的 `ArgumentRoleSpec` 将 subject 指向 object。关系型多方
事件使用无向投影，并限制参与方数量。节点当前按 `(名称, 类型, 国家)` 临时归一化，因此
属于实体提及图；对于名称和类型一致、且只有一个明确国家候选的实体，投影层会将缺失国家
代码的提及并入该国家节点。该规则不回写数据，也不处理别名，不等同于完成实体消歧的知识图谱。
边上显示 Registry 的规范中文谓词标签；原始多语言 label 按频次聚合后保留在悬浮提示和边详情中。
点击节点会更新底部默认收起的情报摘要栏，用户展开后可查看该投影实体参与的真实情报，
并可按施事、受事或无向参与角色过滤；
点击边则按来源实体、目标实体、规范谓词和方向精确列出支撑关系的情报。最大节点数等图规模
参数只裁剪可视化，不会再次裁剪已经选中关系的证据列表。

地域视图、实体视图和实体时间线统一复用主站的 `ArticleModalManager` 与
`ArticleDetailRenderer`。地域/实体证据卡片点击标题打开弹窗；时间线先展示事件摘要，再由
“查看完整情报”打开同一弹窗。弹窗支持 Esc、点击遮罩或关闭按钮退出，并保留复制链接和新标签
打开作为辅助操作。

登录用户可在节点详情中“指定实体”。编辑器分两步：先在全局实体表或语境实体表中搜索、
选择或添加目标，再设置关联范围。全局目标默认把当前节点名称登记为全局映射；勾选“仅针对
所选情报中的实体生效”后改为多选具体 EntityRef。语境目标必须依赖情报，因此该选项会被
自动勾选且不能取消。保存后关系图不会自动重载，避免大图阻塞，用户可在提示条中手动刷新。
